# Changelog — NarutoSenki V2

## v1.0.0 — AI vs AI Spectate

### ✦ Mode Baru: AI VS AI (Spectate)
Nonton AI lawan AI — kamu cukup menonton, semua input dikunci (tombol pause tetap aktif).

◆ Pilih jumlah fighter: **1v1** ◆ **2v2** ◆ **3v3** ◆ **4v4** ◆ **5v5**
◆ Kamera otomatis mengikuti titik tengah pertarungan
◆ Panel statistik live: skor kill tiap tim + K/D tiap fighter
◆ Spawn acak per tim, hero pilihanmu atau acak

### ★ Visual Baru
◆ **Start menu**: desa ninja di bawah bulan purnama raksasa
◆ **Layar pilih karakter**: battlefield malam biru / senja merah (warna mengikuti mode)
◆ **Layar pilih mode**: background bulan purnama

### ✓ Perbaikan Teknis
◆ Fix include path `fmt` di modul lua — build Android sempat gagal karenanya
◆ Fix `NDK_MODULE_PATH` cross-platform (sebelumnya hanya jalan di Windows)
◆ GitHub Actions: build APK otomatis setiap push

### ● Info APK
◆ Android 5.0+ ◆ arm64-v8a & armeabi-v7a ◆ debug-signed
◆ Cara install: download APK → izinkan *Install unknown apps* → buka file → Install
